# 강호행 세계관 분석 (3판)

지금 게임 데이터에 들어 있는 세계관을 다시 정리했습니다. 3판에서는 2판이 모순이나 불명확으로 적은 설정을 데이터에서 직접 고쳤습니다. 가장 큰 변경은 전대 천마를 없앤 것입니다. 천마는 처음부터 한 사람이고, 백 년 전의 천마와 지금의 천마는 같은 사람입니다. 새끼 영물은 구미호 은비와 헷갈리지 않게 흰 새끼 범 설백으로 바꿨습니다.

표시
- **[명시]** 데이터 문장에 그대로 적혀 있는 설정
- **[암시]** 여러 문장을 엮으면 그렇게 읽히지만 단정하지 않은 설정
- **[모순]** 서로 부딪치는 설정

조사 범위: 사건 본문과 선택지와 결과, 적과 동료의 이름과 설명과 대사, 소속, 출신, 결말, 상점 문장을 주제어로 검색해 읽었습니다. 사건 2천여 개의 모든 문장을 한 줄씩 다 읽은 것은 아닙니다.

## 1. 현재 확정된 설정

### 1-1. 시대와 큰 흐름

| 때 | 일 |
|---|---|
| 백여 년 전 | 천마가 태어나 열 살에 제 아비를 죽인다(천마의 유모). 이미 현경에 이른 천마가 무림을 피로 물들이고 사라진다. 사람들은 죽었다고 여긴다. |
| 백 년 전부터 | 천마가 천마봉 깊은 비동에서 폐관을 시작한다. 신교는 혈교를 꺾고 피 연못과 혈마대를 빼앗는다. |
| 서른 해 전 | 면왕 왕백로가 천하십대고수였다. |
| 열다섯 해 전 | 붉은 소매의 신교가 아이들을 피 연못으로 끌고 간다(혈지생환). |
| 강호행 1달 | "백 년 전 죽었다는 천마가 돌아온다"는 소문 속에 하산한다. |
| 25달(2장) | 낙양에서 무림맹 호법, 사도련 책사, 붉은 옷의 신교 여인이 사람을 모은다. |
| 49달(3장) | 청운장 도륙, 붉은 손자국. 정파와 사파, 신교가 얽힌다. 사도에게는 한 철의 동맹 제안이 온다. |
| 60달 | 태산에서 십 년 만의 비무대회. |
| 73달(4장) | 생사경을 이룬 천마의 깃발이 오르고 정마대전이 시작된다. 낙양이 불탄다. |
| 97달(5장) 첫머리 | 승패는 아직 가려지지 않았다. 4장에서 고른 편, 한 철의 동맹, 맹주의 생사, 낙양을 지켰는지에 따라 전황 문장이 달라진다. |
| 97달(5장) | 신교 사자가 교주의 인장이 찍힌 초대장을 전한다. 이름이 낮으면 하오문 전서구로 온다. |
| 120달 | 천마봉의 결전. |

### 1-2. 힘의 기준

| 경지 | 인물 |
|---|---|
| 생사경 | 천마 |
| 현경 | 무림맹주 하후창, 십이마장, 백 년 전 천마의 그림자, 무명노인, 천년 이무기, 흑룡, 생사의 문지기 |
| 화경 | 신교 장로 음풍마군 고진, 친위대주 석면귀 오문, 맹 대장로와 집법당주, 천하십대고수 부동검 남천우, 북해빙궁 소궁주, 산군, 철갑 현귀, 불가사리, 천년 백사, 해치 |
| 초절정 | 구파일방과 세가의 장로, 사도련 대향주, 하오문주, 혈교 좌호법, 만년 빙잠, 금섬, 금안신조, 구미호 은비 |
| 절정 | 손꼽히는 후기지수, 작은 세력의 우두머리 |

### 1-3. 세력

**구파일방**
- 성격: [명시] 모두 정도이고 무림맹의 중심입니다. 문파마다 초절정 장로가 사문 시험을 맡습니다. 천하십대고수의 빈자리는 구파일방과 오대세가의 원로들이 정합니다.
- 개방: [명시] 방주가 오래 몸에 쌓인 독으로 쓰러졌고, 범인은 장로 가운데 하나입니다(개방제자 출신). 장로회가 타구봉을 내주고, 쪽박을 새 방주에게 넘기는 갈래가 있습니다.

**오대세가**
- [명시] 남궁과 팽가는 천마신교에 멸문했습니다. 신교 사자는 "교주께서는 창궁을 불태운 날을 기억하십니다"라고 말해, 남궁의 멸문이 교주의 뜻이었음을 밝힙니다.
- [명시] 사천당가, 모용, 제갈은 정파 명문이고 장로와 직계가 비무와 사건에 나옵니다.

**그 밖의 큰 세력**
- [명시] 북해빙궁(사절단이 낙양을 지남, 소궁주 화경), 남만 야수궁(대술사가 독충으로 고을을 시험), 오독문(장로 하나), 장강수로채, 녹림 칠십이채.
- 관: [명시] 동창, 금의위(표국을 무너뜨린 복면인이 금의위 복색이었다는 실마리), 육선문, 철혈대.

**천마신교**
- [명시] 천마를 하늘로 섬기고 교주의 인장으로 명을 내립니다.
- [명시] 교주 아래 십이마장(현경), 장로(화경), 친위대, 호교대, 혈마대, 암살귀, 사냥개, 붉은 소매의 사자, 피 연못의 심판자가 있습니다.
- [명시] 피 연못은 본래 혈교의 것이었으나 신교가 혈교를 꺾으며 빼앗았습니다. 혈마대도 그때 거두어 다시 길렀습니다. 홍의나찰 적연은 "교단의 장로였고 사람을 연못에 던지던 손"입니다.
- [명시] 붉은 소매는 신교의 표식입니다. 남궁 멸문의 붉은 표식, 생환 이야기의 수레, 2장의 붉은 옷 여인이 모두 신교입니다. 혈교 승려는 잿빛 가사를 입습니다.
- [명시] 2장의 붉은 옷 여인은 신교의 사람이고, 신교에 오라며 붉은 단약을 내밉니다.

**천마**
- [명시] 생사경. 처음부터 한 사람입니다. 백 년 전 무림을 피로 물들이고 사라졌고, 죽었다고들 했지만 천마봉 깊은 곳에서 백 년을 폐관해 생사경을 이루고 돌아왔습니다. 백여 년 전에 태어났고, 젖어미의 딸이 아직 마을 끝집에 살아 있습니다. 열 살에 제 아비를 죽였고 왼쪽 옆구리에 그 칼자국이 있습니다.
- [명시] "백 년을 기다렸다"고 말하고, 정이니 마니 하는 것은 힘없는 자들의 변명이라고 합니다.
- [명시] 권마와 싸운 적이 있습니다. 권마는 다섯 수를 버텼고 천마의 가슴에 주먹 자국을 남겼습니다.
- [명시] 무림초출 출신에게는 끝내 "네 사부가 누구냐"고 묻습니다.

**백 년 전의 천마**
- [명시] 천마의 옛 비동은 백 년 전 천마가 숨어 폐관을 시작한 곳입니다. 일지에는 그때 그가 무엇을 두려워했는지 적혀 있습니다.
- [명시] 백 년 전 천마의 그림자(현경)는 비동의 구결이 사람의 꼴을 이룬 것으로, 폐관 전의 천마입니다. "백 년 뒤의 나를 만나러 가느냐. 그 전에 백 년 전의 나부터 넘어라."라고 말합니다.
- [명시] 다른 천마, 첫 천마, 후계 다툼은 없습니다.

**사도련**
- [명시] 사파 방회들이 이익으로 뭉친 뒷세력. 련주 철혈귀 공손야의 장부가 곧 법입니다. 그 아래 향주, 책사, 대향주 도흔 오광(초절정)이 있고, 한 철의 동맹도 련주의 뜻으로 제안됩니다.
- [명시] 사도를 걷는 무인은 한 철의 동맹으로 무림맹과 손잡거나, 맹주를 베거나, 거절할 수 있습니다. 그 결과가 4장과 5장의 문장에 남습니다.

**무림맹**
- [명시] 맹주 천일검 하후창(현경). 대장로 태산검 배원철, 집법당주 철면판관 서도진, 맹주의 호법 쌍벽검 문천기, 추격대주 파풍검 진관, 순찰조가 있습니다.
- [명시] 맹주는 독에 쓰러졌다 깨어나는 일이 있고(맹주의 아들), 범인은 맹의 호법입니다. 어린 아들이 뒤를 잇는 결말이 있습니다.
- [명시] 맹주가 쓰러지면 맹주가 나오는 사건과 맹주의 아들 이야기가 다시 오지 않습니다.
- [명시] 맹주의 아들 이야기가 이어지는 동안(맹주가 독에 누워 있는 동안)에는 무림맹 회의, 맹주의 마지막 회의, 맹주의 칼, 맹주의 권유, 한 철의 동맹이 오지 않습니다.

**그 밖의 독립 세력과 특수 세력**
- 하오문: [명시] 소문을 먼저 사는 쪽에 파는 것이 규칙이고, 문주는 천면노수 소낭입니다.
- 녹림맹: [명시] 늙은 녹림왕이 산채 칠십이 곳을 거느리고, 철부 장칠의 인연 끝에 녹림왕이 직접 칠십이 채를 장칠에게 넘깁니다.
- 살막: [명시] 막주는 얼굴 없는 무면객이고 장부와 패로 살수를 부립니다.
- 흑사방, 귀문교: [명시] 도박과 밀수의 방회, 죽은 자를 부리는 산속의 사교.
- 혈교: [명시] 피를 경전으로 삼고 개조 혈마를 받드는 오랜 마도 교단. 신교에게 피 연못과 혈마대를 빼앗기고 산속으로 밀려났습니다. 잔당이 혈마 부활을 외우고, 유적의 혈마의 잔영은 개조 혈마가 남긴 의지입니다.
- 오독문, 야수궁, 북해빙궁: [명시] 오독문은 남만에서 올라와 야수궁과 손잡았고, 야수궁은 신교와 손잡고 남쪽을 흔듭니다. 북해빙궁은 정마대전에서 어느 편에도 서지 않고 지켜봅니다.
- 철혈대: [명시] 관도를 지키는 지방 군영의 정예입니다.

**영물과 신수**
- 흉한 영물: [명시] 산군 백액호, 철갑 현귀, 천년 이무기, 흑룡, 금안신조, 불가사리, 천년 백사, 만년 빙잠, 금섬, 천년 혈망.
- 선한 영물: [명시] 산신의 사자 백록과 시비를 가리는 해치. 도우면 정도로, 값을 받고 팔면 사도로, 해치면 마도로 기웁니다. 해치는 정도에게 고개를 숙이고 마도에게 뿔을 겨눕니다.
- 구미호 은비: [명시] 천 년을 산 경국지색의 여우입니다. 천마가 산의 영물들의 내단을 거두어 갔다고 말하고, 약조하면 결전에 옵니다.
- 영수 백호 설백: [명시] 덫에 걸린 흰 새끼 범으로 만나는 새끼 영물 인연입니다. 길러 내면 백호가 되어 결전에 옵니다. 은비와는 이름도 길도 다릅니다.

### 1-4. 출신과 세계의 연결

| 출신 | 세계와 이어지는 점 | 결전의 조력 |
|---|---|---|
| 무림초출 | 화경 끝자락의 사부, 칠십 년 전 사부를 아는 반로환동 노인 | 같은 날 하산한 벗 |
| 남궁세가 | 신교가 태운 본가, 위패를 진 옛 마부 | 남궁의 식솔 |
| 하북팽가 | 신교의 야습, 네 형의 칼 | 큰형의 아들이 산 아래를 맡음 |
| 표국표사 | 금의위 복색의 복면인, 정체 모를 표물 | 흩어졌던 표사들 |
| 개방제자 | 방주 독살과 범인 장로 | 되살린 분타 |
| 권마계승 | 천마와 다섯 수를 나눈 권마 | 권마의 그림자 |
| 혈지생환 | 신교의 피 연못과 삼백 아이 | 비석에 새긴 이름들 |
| 하오문 | 팔린 소문과 불탄 마을 | 거짓 소문으로 흩은 호위 |

## 2. 모순되거나 불명확한 설정

### 2-1. 3판에서 고친 것

| 2판의 문제 | 고친 설정 |
|---|---|
| 첫 천마와 지금 천마 사이 | 전대 천마를 없앴습니다. 천마는 한 사람이고, 비동은 그가 폐관을 시작한 곳, 그림자는 폐관 전의 그입니다. 비동, 그림자, 천마의 설명, 상점 문장을 모두 고쳤습니다. |
| 혈마는 누구인가 | 혈마는 혈교의 개조이고, 신교가 혈교를 꺾으며 피 연못과 혈마대를 빼앗았습니다. |
| 사도련의 머리 | 련주 철혈귀 공손야를 두었습니다. 한 철의 동맹도 련주의 뜻입니다. |
| 맹주가 독에 쓰러진 시기 | 맹주의 아들 이야기 동안 맹주가 나오는 다섯 사건을 막습니다(`not_chain`). |
| 붉은 소매 | 신교의 표식으로 굳혔습니다. 혈교 승려는 잿빛 가사입니다. |
| 정마대전의 결과 | 5장 첫 문장을 "아직 가려지지 않았다"로 바꾸고, 맹주를 벤 경우, 동맹, 무림맹 편, 낙양 수호, 신교 소속에 따라 전황 문장을 붙였습니다. |
| 살막 막주, 녹림왕의 뒤 | 막주는 무면객, 장칠 인연 끝에 녹림왕이 칠십이 채를 넘깁니다. |
| 오독문, 철혈대, 빙궁, 야수궁 | 소속과 정마대전의 편을 한 줄씩 정했습니다. |
| 개방 방주의 생사 | 다시 확인하니 이미 이어집니다. 방주가 독에 쓰러지는 것은 개방제자 출신의 강호행뿐이고(녹죽봉, 타구봉, 분타 이야기가 모두 그 출신 전용), 다른 출신의 강호행에서 방주는 살아 있어 개방 사건에 직접 나옵니다. 이 원칙을 여기 적어 둡니다. |
| 새끼 영물 은비 | 흰 새끼 범 설백으로 바꿨습니다. |

### 2-2. 남은 것

- 비어 있는 자리: 십이마장 다섯 자리, 혈교 교주, 구파일방 장문인, 오대세가 가주(남궁과 팽가 제외), 천하십대고수 여덟 자리에 이름이 없습니다.
- 위상에 비해 가볍게 쓰인 곳: 구파일방은 장로의 비무와 회의 말석의 다툼으로 주로 나오고, 문파 스스로 큰일을 겪는 사건이 드뭅니다.
- 천마의 폐관 일지에 "그가 무엇을 두려워했는지"의 내용은 여전히 적혀 있지 않습니다. 두려움의 대상을 정해 결전 대사와 잇는 여지가 있습니다.

---

## 3. 향후 개선 제안

### 3-1. 먼저 정할 줄기

1. **천마가 두려워한 것**: 백 년 전 폐관의 까닭을 한 줄로 정합니다. 예를 들면 권마의 주먹 자국이나 늙어 죽는 것을 두려워했다는 식으로 두면 비동 일지, 권마 이야기, 결전 대사가 이어집니다.
2. **천하십대고수 명단**: 비어 있는 여덟 자리를 정하면 큰 인물을 여러 사건에 돌려 쓸 수 있습니다.

### 3-2. 비어 있는 자리 채우기

- 혈교 교주, 비어 있는 십이마장 다섯 자리에 이름과 성격을 줍니다. 장마다 나눠 쓰고 쓰러뜨리면 사라지게 합니다.
- 구파일방 장문인과 오대세가 가주를 한 줄씩 정하고, 문파마다 큰일 하나를 사건으로 둡니다. 장문인 교체, 비전 도난, 신교와의 밀약 의혹 같은 것입니다.
- 천하십대고수 열 명을 모두 정합니다. 정파 넷, 사파 셋, 마도 둘, 은거 하나처럼 나누면 여러 사건의 큰 인물로 돌려 쓸 수 있습니다.

### 3-3. 시간과 인물의 일관성

- 개방 방주처럼 출신에 따라 생사가 갈리는 인물은 지금처럼 "출신 이야기 밖에서는 살아 있다"는 원칙을 지킵니다.

### 3-4. 세력의 격

- 동창과 금의위의 목적을 한 줄씩 정하고 정마대전에서 기대는 편을 정합니다.
- 구파일방과 오대세가는 비무 상대보다 판을 움직이는 쪽으로 더 씁니다. 맹 회의에서 문파마다 다른 입장, 세가끼리의 혼사와 이권 다툼 같은 것입니다.
- 선한 영물(백록, 해치)을 산신이나 하늘의 뜻과 이어 두면, 마도로 기운 무인이 되돌아올 수 있는 길로도 쓸 수 있습니다.
