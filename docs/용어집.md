# 용어집

원칙: **영어와 영어식 게임 용어를 쓰지 않고, 무협풍으로 쓰되 어색해지면 평범한 우리말을 씁니다.** 예외로 카르마는 그대로 씁니다.

| 쓰지 않는 말 | 쓰는 말 |
|---|---|
| 턴 | 달 |
| 라운드 | 합 |
| 보스 | 마두 |
| 기력 | 내력 |
| 명상 | 운기 |
| 회복(행동) | 요양 |
| 시장 | 장터 |
| 가방, 인벤토리 | 행낭 |
| 도감 | 강호록 |
| 소비품 | 상비약 |
| 무기 | 병기 |
| 방어구 | 호신구 |
| 장비 | 병장기 |
| 특성 | 자질 |
| 숙련도 | 성취 |
| 등급 | 품계 |
| 치명타 | 회심의 일격 |
| 전투 경험 | 실전 경험 |
| 공격력 | 위력 |
| 능력치 | 기량 |
| 업적 | 공적 |
| 인카운터 | 인연 |
| 내 상태 | 신상 |
| 엔딩 | 결말 |
| 심공(화면) | 심법 |
| 호구 | 갑의 (갑의가 들어간 이름으로 쓴다) |
| 최종전 | 천마와의 결전 |
| 로그라이크 | 쓰지 않는다. 게임 이름은 강호행 |

체력, 탐색, 수련, 합, 도구, 강호행, 입문서, 설정, 이어하기, 카르마, 카르마 상점은 그대로 씁니다. 문파, 경지, 별호, 내상, 점혈, 비기, 비급, 초식처럼 무협에서 자연스러운 말은 그대로 살립니다.

코드 안의 키 이름(`소비품`, `무기`, `명상`, `휴식` 등)은 저장 호환을 위해 그대로 둡니다. 화면에 쓸 때만 위 말로 바꿉니다.
