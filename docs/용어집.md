# 용어집

게임 안과 메뉴에서 쓰는 말은 무협풍으로 통일합니다. 새 글을 쓸 때 왼쪽 말을 쓰지 말고 오른쪽 말을 씁니다.

| 일반 게임 용어 | 이 게임의 말 |
|---|---|
| 턴 | 달 |
| 라운드 | 합 |
| 체력 | 기혈 |
| 기력, MP | 내력 |
| 능력치 | 기량 |
| 탐색 | 행각 |
| 명상 | 운기 |
| 휴식, 회복 행동 | 요양 |
| 전투 경험 | 실전 경험 |
| 숙련도 | 성취 |
| 등급 | 품계 |
| 무공 진화 | 승급 |
| 비기 해방 | 터득 |
| 공격력 | 위력 |
| 치명타 | 급소 타격 |
| 무기 / 방어구 / 장비 | 병기 / 호신구 / 병장기 |
| 방어력 | 호신강기 |
| 소비품 / 무공서 | 상비약 / 비급 |
| 인벤토리, 가방 | 행낭 |
| 상점, 시장 | 장터 |
| 품절 | 동남 |
| 카르마 | 공덕 |
| 특성 / 슬롯 | 천품 / 자리 |
| 해금 | 개방 |
| 회차 | 생 |
| 도감 | 강호록 |
| 상태 창 | 행장 |
| 설정 | 채비 |
| BGM | 풍류 가락 |
| 이어하기 | 강호행 잇기 |
| 저장 데이터, 내보내기, 가져오기 | 행적, 베껴 두기, 불러오기 |
| 게임 포기 | 강호를 떠난다 |
| 튜토리얼 | 입문서 |
| 일반 적 / 보스 | 잡배 / 마두 |

코드 안의 키 이름(`hp`, `탐색`, `current_karma` 등)은 저장 호환을 위해 그대로 둡니다.

게임 제목의 "로그라이크"는 제목이라 유지합니다.
