# 용어집

원칙은 하나입니다. **영어와 영어식 게임 용어를 쓰지 않고, 어색해지면 억지로 무협풍으로 만들지 않습니다.** 평범한 우리말이 자연스러우면 평범한 우리말을 씁니다.

| 쓰지 않는 말 | 쓰는 말 |
|---|---|
| 턴 | 달 |
| 라운드 | 합 |
| BGM | 배경 음악 |
| 슬롯 | 칸 |
| 보스 | 마두 |
| VS | 대 |
| 인벤토리 | 가방 |
| 튜토리얼 | 입문서 |
| 카르마 | 공덕 |

체력, 기력, 능력치, 탐색, 수련, 명상, 회복, 숙련도, 등급, 공격력, 치명타, 무기, 방어구, 시장, 가방, 도감, 특성, 설정, 이어하기는 그대로 씁니다. 문파, 경지, 별호, 내상, 점혈, 비기, 비급, 초식처럼 무협에서 자연스러운 말은 그대로 살립니다.

코드 안의 키 이름은 저장 호환을 위해 그대로 둡니다. 게임 제목의 "로그라이크"는 제목이라 유지합니다.
