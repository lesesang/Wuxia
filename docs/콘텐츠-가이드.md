# 콘텐츠 가이드

`www/data/`의 JSON만 고쳐서 내용을 늘리는 방법입니다. 고친 뒤 `npm test`를 돌리면 없는 적이나 무공을 가리킨 실수를 잡아 줍니다.

| 파일 | 내용 |
|---|---|
| `events_random.json`, `events_jianghu.json` | 탐색 중 사건 |
| `events_sect.json` | 문파와 출신별 이야기 |
| `events_story.json` | 정해진 달의 줄거리 |
| `enemies.json` | 적 |
| `skills.json` | 무공, 심공, 경공 |
| `market.json` | 시장 품목 |
| `traits.json` | 특성 |
| `sects.json` | 문파 |
| `fortunes.json` | 기연 |
| `flavor.json` | 달마다 바뀌는 문장, 행동 문장, 명성 등급, 별호 |
| `origins.json`, `realms.json`, `endings.json`, `chapters.json`, `balance.json` | 출신, 경지, 엔딩, 챕터, 난이도 곡선 |

## 사건

```json
"새사건": {
  "chapters": [2, 3],
  "requires": {"min_fame": 8},
  "title": "제목",
  "text": "본문",
  "choices": [
    {
      "label": "선택지",
      "requires": {"min_silver": 30},
      "outcomes": [
        {"weight": 2, "text": "결과 문장", "effects": {"silver": -30, "stats": {"martial": 3}}},
        {"weight": 1, "text": "다른 결과", "effects": {"battle": "산적"}}
      ]
    }
  ]
}
```

이벤트 이름은 모든 사건 파일을 통틀어 겹치면 안 됩니다.

## 상황별 반응

같은 사건이라도 출신, 사문, 상태, 무공, 지닌 물건에 따라 다르게 반응하게 할 수 있습니다. 모든 경우를 만들 필요는 없고 특별한 몇 가지만 넣습니다.

```json
"variants": [
  {
    "requires": {"item": "해독단"},
    "tag": "해독단",
    "text": "조건이 맞으면 본문을 이것으로 바꿉니다. 생략 가능",
    "choices": [
      {"label": "해독단을 먹인다", "outcomes": [{"text": "결과", "effects": {"consume_item": "해독단", "stats": {"mind": 2}}}]}
    ]
  }
]
```

- 본문은 조건이 맞는 첫 반응의 것을 씁니다. 선택지는 조건이 맞는 반응의 것이 모두 기본 선택지 앞에 붙습니다.
- `tag`는 선택지 앞에 금색 표시로 나옵니다.
- 선택지에 `"hidden": true`를 넣으면 조건이 안 맞을 때 잠긴 채 보이지 않고 아예 숨습니다.

적의 대사도 같습니다. 적 데이터에 `"intros": [{"requires": {"origin": "남궁세가"}, "text": "대사"}]`를 넣습니다.

## 소속 규칙

사문이 있는 무인에게 새 소속에 들어가는 선택지를 보이면 안 됩니다.

- 문파 입문 사건의 `requires`에는 `"no_sect": true`를 넣습니다.
- 무림맹, 사도련, 마교처럼 세력에 서는 선택지에는 `"requires": {"sect_side": "정도"}`와 `"hidden": true`를 넣습니다. 사문이 없거나 사문 성향이 같을 때만 보입니다.

**requires:** `origin`, `flag`, `not_flag`, `any_flag`, `min_silver`, `realm_min`, `skill`, `no_skill`, `sect`, `no_sect`, `min_fame`, `stat_min`, `alignment_min`, `max_alignment`, `has_sect`, `sect_side`, `item`, `equip`, `any_skill`, `injured`, `dominant`, `main_category`

**effects:** `stats`, `hp_pct`, `qi_pct`, `silver`, `set_silver`, `alignment`, `flags`, `skill`, `mastery`, `item`, `equip`, `boss_weaken`, `fame`, `injury`, `join_sect`, `leave_sect`, `consume_item`, `main_skill`, `random_skill`, `battle`, `gauntlet`, `final_battle`, `ending`

사건과 기연의 능력치 상승은 적힌 값의 30%가 적용됩니다(최소 1). (`www/js/events.js`의 `EVENT_STAT_SCALE`)

## 적

`hp`와 `attack`은 `level` 달 기준 값이고 시간이 지나면 `balance.json`의 곡선만큼 강해집니다. `tools/fit_enemies.py`가 등급 목표와 `hp_style`, `attack_style`로 이 값을 계산하니 개별 조정은 style 값으로 하세요.

`chapters`와 `weight`는 탐색에서의 등장 조건입니다. 이벤트 전용 적은 `chapters`를 빈 목록으로 둡니다.

`specials`의 필살기는 `every` 합마다 발동하고 직전 합에 예고됩니다. `mult`, `poison`, `qi_drain`, `heal_pct`, `seal`, `injury`를 쓸 수 있습니다. `phases`는 체력이 줄었을 때 위력을 올립니다.

## 시장 품목

`markets`는 시장 등급입니다. 1~4는 챕터(5장은 4), 5는 수상한 누군가입니다. `always`는 반드시 진열, `dominant`는 해당 성향 전용, `consumable`은 가방에 넣어 쓰는 물건입니다.

무기의 `equip` 효과에 `style`(검법, 도법, 창법, 봉법, 권법, 장법, 암기)을 넣으면 그 계열 전용이 됩니다. 주무공과 맞지 않으면 3/4만 적용되고, 익힌 계열의 무기와 비급은 시장에 더 자주 나옵니다.

**effects:** `heal`, `stat`, `equip`, `skill`, `boss_weaken`, `cure`
