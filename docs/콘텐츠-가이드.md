# 콘텐츠 가이드

`www/data/`의 JSON만 고쳐서 내용을 늘리는 방법입니다. 고친 뒤 `npm test`를 돌리면 없는 적이나 무공을 가리킨 실수를 잡아 줍니다.

| 파일 | 내용 |
|---|---|
| `events_random.json`, `events_jianghu.json` | 탐색 중 사건 |
| `events_sect.json` | 문파와 출신별 이야기 |
| `events_story.json` | 정해진 턴의 줄거리 |
| `enemies.json` | 적 |
| `skills.json` | 무공, 심공, 경공 |
| `market.json` | 시장 품목 |
| `traits.json` | 특성 |
| `sects.json` | 문파 |
| `fortunes.json` | 기연 |
| `flavor.json` | 달마다 바뀌는 문장, 행동 문장, 명성 등급, 별호 |
| `origins.json`, `realms.json`, `endings.json`, `chapters.json` | 출신, 경지, 엔딩, 챕터 |

## 사건

```json
"새사건": {
  "chapters": [2, 3],
  "requires": {"min_fame": 8},
  "title": "제목",
  "text": "본문",
  "choices": [
    {
      "label": "선택지",
      "requires": {"min_silver": 30},
      "outcomes": [
        {"weight": 2, "text": "결과 문장", "effects": {"silver": -30, "stats": {"martial": 3}}},
        {"weight": 1, "text": "다른 결과", "effects": {"battle": "산적"}}
      ]
    }
  ]
}
```

이벤트 이름은 모든 사건 파일을 통틀어 겹치면 안 됩니다.

**requires:** `origin`, `flag`, `not_flag`, `any_flag`, `min_silver`, `realm_min`, `skill`, `no_skill`, `sect`, `no_sect`, `min_fame`, `stat_min`, `alignment_min`, `max_alignment`

**effects:** `stats`, `hp_pct`, `qi_pct`, `silver`, `set_silver`, `alignment`, `flags`, `skill`, `mastery`, `item`, `equip`, `boss_weaken`, `fame`, `injury`, `join_sect`, `battle`, `gauntlet`, `final_battle`, `ending`

사건과 기연의 능력치 상승은 적힌 값의 60%가 적용됩니다. (`www/js/events.js`의 `EVENT_STAT_SCALE`)

## 적

`chapters`와 `weight`는 탐색에서의 등장 조건입니다. 이벤트 전용 적은 `chapters`를 빈 목록으로 둡니다.

`specials`의 필살기는 `every` 라운드마다 발동하고 직전 라운드에 예고됩니다. `mult`, `poison`, `qi_drain`, `heal_pct`, `seal`, `injury`를 쓸 수 있습니다. `phases`는 체력이 줄었을 때 공격력을 올립니다.

## 시장 품목

`markets`는 등장하는 시장 번호(1~4차, 5는 수상한 누군가)입니다. `always`는 반드시 진열, `dominant`는 해당 성향 전용, `consumable`은 가방에 넣어 쓰는 물건입니다.

**effects:** `heal`, `stat`, `equip`, `skill`, `boss_weaken`, `cure`
