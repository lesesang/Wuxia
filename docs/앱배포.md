# 앱으로 출시하기

지금 게임은 그대로 앱에 넣을 수 있게 만들어 두었습니다.

## 지금도 되는 것: 홈 화면 설치

브라우저에서 게임을 연 뒤 메뉴의 "홈 화면에 추가"를 고르면 아이콘이 생기고 주소창 없이 전체 화면으로 실행됩니다. 인터넷이 없어도 돌아갑니다.

## 앱 스토어 출시 준비

[Capacitor](https://capacitorjs.com)로 `www/` 폴더를 그대로 안드로이드와 iOS 앱으로 포장합니다. 설정은 `capacitor.config.json`에 있습니다.

필요한 것:

- 안드로이드: Android Studio, Google Play 개발자 계정
- iOS: Mac, Xcode, Apple Developer 계정

```
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
npx cap add android
npx cap add ios
npx cap sync
npx cap open android
```

아직 실제 앱으로 빌드해 시험하지는 않았습니다.

## 출시 전에 할 일

- 앱 이름, 아이콘, 패키지 이름(`capacitor.config.json`의 `appId`) 확정
- 개인정보 처리방침: 게임은 서버로 아무것도 보내지 않고 기록을 기기에만 저장합니다
- 글꼴 라이선스 표기: `www/fonts/OFL.txt`
- "기록 내보내기"는 앱 안에서 파일 저장 방식이 달라 공유 플러그인이 필요할 수 있습니다
- 안드로이드 뒤로 가기 버튼 동작 시험: 창이 열려 있으면 창이 닫히도록 해 두었습니다

## 앱에 맞춰 만들어 둔 것

- 서버 없이 기기에서 실행, 외부 요청 없음
- 글꼴과 아이콘 내장
- 노치와 하단 제스처 영역을 피한 화면, 44px 이상의 터치 버튼
- 앱이 뒤로 가면 BGM 정지
- 저장소 접근을 `www/js/storage.js` 한 파일에 모음. 네이티브 저장소로 바꿀 때 이 파일만 고치면 됩니다
